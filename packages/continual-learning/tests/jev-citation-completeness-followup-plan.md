# Prospective citation-completeness learning repair

Current whole-production baseline and Noul trial both held the Chinese toolchain
candidate; Noul additionally held an English lasting report preference. The Noul
trial is rejected and not a production feature. @jev-memory-support-noul-adoption-decision.json
records numerical evidence and the unchanged gold corpus. @jev-memory-support-citation-coverage-inspection.json
records a code-visible citation distinction; it is not the model's causal explanation.

The user requested that frozen evidence actually support each generated Memory.
Current optimized support reads original cited entries, while counters read the
complete snapshot. A source statement already in that snapshot can be absent from
the selected support list. Generation and the existing one-shot semantic repair
may add original exact citations, subject to the same normalizer, privacy and
identity checks; `validateIncrementalRepairRetention` preserves names/intents rather
than freezing bad citations. Do not change Jev thresholds or grant new authority.

Before implementation, define these Given/When/Then scenarios and RED regressions:

- Given a proposed current project fact with only a future-use user citation and
  a verified current-state tool observation in the same frozen snapshot, when
  correcting its evidence, then retain the exact name/body/classification and
  original user citation, and add only the exact existing verified observation.
  Whole original support/description/counter/relationship checks must still decide.
- Given speculation, an unresolved temporary fault, a later revocation or an
  unrelated observation, when providing additional original citations, then no
  supported current fact or durable obligation is invented and unsafe plans stay held.
- Given privacy or identity changes, out-of-snapshot quotes or classification
  derived differently from the added evidence, when validating a repair, then
  reject it; Jev cannot change storage class or Harness. No unauthorized write.
- Given insufficient citation budget or unclear relevance, when a bounded repair
  cannot establish every claim, then preserve the existing proposal. Do not drop
  evidence, infer a verified result or grow repair/call limits.

Use the known16cases only as development. A controlled citation augmentation may
be researched for public synthetic inputs, not blindly applied in production;
for real candidates the generation model selects relevant exact sources from the
same frozen dossier. Preserve original failed studies and pre-change prompt/source
bytes. Compare unchanged before/after judge using frozen prospective candidates,
complete all-request offline preflight, exact numeric observations and pinned model.
Require fewer valid holds and no unsafe accepts before fresh heldout, then verify
actual generation/repair and isolated multi-repository Docker workflow effects.
No favorable re-query of the historical R13 plan, mutable gold, threshold changes,
raw private state logs or mock-as-real claims.
