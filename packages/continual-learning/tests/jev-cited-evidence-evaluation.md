## 行为改动

新 Memory 候选先由代码验证结构、隐私和冻结证据原文引用；支持判断只读取
完整的被引用条目及已经读取的已有 Memory。随后按原索引审查**全部**冻结
条目，包括工具结果与后来用户纠正。Harness 使用父进程已经验证的原文引用，
保留持久授权、命令参数范围、说明忠实度及原生执行权限检查。

完整条目不能截断；每窗口最多 24,000 bytes、最多八个窗口。请求按实际
序列化大小预拆分，每次最多32问题/64,000 bytes，最多十二次、四个并发。
全部输入隐私检查及请求复制在第一次外发前完成。失败、取消、版本不一致或
不确定均保留整个提案；不完整窗口不计入覆盖。不增加命令或改变写入权限。
修改/删除/混合 Memory 计划仍使用旧完整上下文路径，可能容量停止。

生成提示要求最小持久事实，避免扩写布局、历史数字、临时环境处置；任务执行
协议和本次简短回执要求不能自动成为长期偏好。既有知识不能为缩短候选而删除。
