## CRITICAL: One question at a time, with a recommendation

Run the [grilling](grilling.md) discipline relentlessly: ask one question at a time using the `matt_pocock_ask` interactive selection tool, provide suggested options with a recommended option marked "(Recommended)" passed as the required recommended value, and allow the user to type custom answers. The deadline adopts the recommendation, so no question waits indefinitely. Wait for the reply before continuing. Do not act until the user confirms shared understanding.
