## English

Your magpie catalog, inside Pi.

Models and routing groups appear in one picker, with the catalog refreshed from your gateway. Set it up with `/login magpie`.

`pi install npm:@fradser/pi-magpie`

Thanks to @yetone for creating magpie!

https://github.com/FradSer/pi-packages/tree/main/packages/magpie

## 中文备选

把 magpie 的模型目录带进 Pi。

模型和路由组出现在同一个选择器中，目录从网关刷新。安装后运行 `/login magpie`，填入网关地址和密钥即可连接。

`pi install npm:@fradser/pi-magpie`

感谢 @yetone 创建了 magpie！

https://github.com/FradSer/pi-packages/tree/main/packages/magpie
