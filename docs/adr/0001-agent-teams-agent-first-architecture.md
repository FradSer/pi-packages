# Make Agent the durable cross-project identity

Agent Teams will treat an Agent as a persistent cross-project identity whose user definition is authoritative and whose project definitions specialize the same identity. Work executes in isolated Work Sessions and replaceable Process Incarnations; project knowledge remains in Project Memory, while each persisted Agent's own folder records only capability-focused Agent Memory. This replaces the session-bound teammate/process model because retaining both would create competing identity, ownership, and memory semantics.
